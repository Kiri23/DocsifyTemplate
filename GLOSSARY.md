# DocsifyTemplate

Sitios de documentación interactivos sin paso de build: el Markdown de un repo se ve como sitio tal cual.

## El sitio

**site.js**:
El script que un sitio carga en su index.html para levantar Docsify 5 con el tema, el import map y los componentes de este repo ya configurados.
_Avoid_: el loader, el script de Docsify
